# OV2640 摄像头实现计划

> **供执行代理使用：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 逐任务执行本计划；步骤使用复选框追踪。

**目标：** 在 ESP32-S3 上实现 OV2640 初始化、运行时 JPEG 画质调节和连续内存取帧。

**架构：** `BSP/CAMERA` 独占 `esp32-camera` 配置、初始化状态和帧缓冲生命周期；`main.c` 创建唯一的消费任务，逐帧记录状态后归还帧缓冲。

**技术栈：** ESP-IDF 5.5.5、C、FreeRTOS、`espressif/esp32-camera`、PSRAM。

## 全局约束

- 目标芯片为 ESP32-S3，板级连线必须匹配 `E:\ESP32\esp32-s3-cam`。
- 不增加 SD 卡、文件系统、Wi-Fi 或 Web 服务器功能。
- 默认参数为 JPEG、QVGA、10 MHz XCLK、两个 PSRAM 帧缓冲区和 `CAMERA_GRAB_WHEN_EMPTY`。
- JPEG 质量合法范围为 0--63，数值越小画质越高且帧更大。
- 每个由 `camera_get_frame()` 成功取得的帧必须恰好调用一次 `camera_return_frame()`。

预期：失败并提示 `camera_init` 未定义，证明后续链接检查可覆盖公开接口。

- [ ] **步骤 2：定义公开头文件**

```c
#include "esp_camera.h"
esp_err_t camera_init(void);
esp_err_t camera_set_quality(int quality);
camera_fb_t *camera_get_frame(void);

```

- [ ] **步骤 3：实现最小且完整的驱动包装**

在 `camera.c` 定义 GPIO4/5/15/13/6/7、D0--D7（11、9、8、10、12、18、17、16）和下列配置：

```c
static const camera_config_t s_config = {
    .pin_pwdn = -1, .pin_reset = -1, .pin_xclk = 15,
    .pin_sccb_sda = 4, .pin_sccb_scl = 5,
    .pin_d0 = 11, .pin_d1 = 9, .pin_d2 = 8, .pin_d3 = 10,
    .pin_d4 = 12, .pin_d5 = 18, .pin_d6 = 17, .pin_d7 = 16,
    .pin_vsync = 6, .pin_href = 7, .pin_pclk = 13,
    .xclk_freq_hz = 10000000, .ledc_timer = LEDC_TIMER_1,
    .ledc_channel = LEDC_CHANNEL_1, .pixel_format = PIXFORMAT_JPEG,
    .frame_size = FRAMESIZE_QVGA, .jpeg_quality = 10, .fb_count = 2,
    .fb_location = CAMERA_FB_IN_PSRAM, .grab_mode = CAMERA_GRAB_WHEN_EMPTY,
};
```

`camera_init` 防止重复初始化并调用 `esp_camera_init`；`camera_set_quality` 拒绝小于 0 或大于 63 的值，检查 `esp_camera_sensor_get()` 后调用 `set_quality`；`camera_get_frame` 只在初始化成功后调用 `esp_camera_fb_get`；`camera_return_frame` 忽略空指针并归还有效帧；`camera_deinit` 仅在初始化后调用 `esp_camera_deinit`。

### Task 3：接入连续取帧任务并验证帧缓冲生命周期

**文件：**

- 修改：`main/main.c`

**接口：**

- 依赖：Task 2 的 CAMERA 接口。
- 产出：系统启动后持续取帧，且每个有效帧均被归还一次。

- [ ] **步骤 1：写出失败的链接检查**

在 `main/main.c` 包含 `camera.h` 并调用 `camera_init()`，在 CAMERA 源文件尚不存在时运行 `idf.py build`。

预期：链接失败，提示 `camera_init` 未定义。

- [ ] **步骤 2：实现连续帧消费任务**

加入 `esp_log.h`、`esp_timer.h` 和 `camera.h`，实现：

```c
static void camera_frame_task(void *arg)
{
    uint32_t frame_count = 0;
    int64_t last_log_us = esp_timer_get_time();
    while (true) {
        camera_fb_t *frame = camera_get_frame();
        if (frame != NULL) { frame_count++; camera_return_frame(frame); }
        else { ESP_LOGW("CAMERA", "获取图像帧失败"); vTaskDelay(pdMS_TO_TICKS(10)); }
        int64_t now_us = esp_timer_get_time();
        if (now_us - last_log_us >= 1000000) {
            ESP_LOGI("CAMERA", "连续取帧：%lu fps", (unsigned long)frame_count);
            frame_count = 0; last_log_us = now_us;
        }
    }
}
```

在 `app_main` 中检查 `camera_init()` 和 `camera_set_quality(10)` 的返回值；成功后调用 `xTaskCreate(camera_frame_task, "camera_frame", 4096, NULL, 5, NULL)`。
