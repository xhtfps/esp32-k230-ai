# GPIO0 SoftAP 网页配网设计

## 范围

为 OV2640 网页预览工程增加按键控制的配网与站点模式切换。设备上电时进入 STA 模式：
优先使用 NVS 中已保存的凭据；若没有保存的凭据，则使用编译期的 `WIFI_SSID` 与
`WIFI_PASSWORD` 作为开发兜底。短按 GPIO0 后，设备启动 SoftAP 热点 `OV2640-Setup`，
手机连接热点并访问配置网页填写目标 Wi-Fi。设备将凭据写入 NVS，关闭热点、切回 STA
并恢复摄像头预览。按住 GPIO0 至少三秒时，设备停止 SoftAP（如正在运行），切换为 STA
并使用 NVS 中最近保存的凭据连接；没有已保存凭据时使用编译期默认凭据。

## 架构

EXIT 模块继续负责 GPIO0 中断、消抖与按键任务：释放前持续时间小于三秒为短按，调用
WIFI 的 `wifi_start_provisioning`；持续时间至少三秒为长按，调用
`wifi_start_station`。WIFI 模块拥有 STA/AP 模式切换、NVS 中凭据读写和连接状态；WEB
模块提供配网页面、提交接口和预览页面。配网期间 HTTP 服务在热点网络上提供配置页，
连接成功后同一服务继续提供摄像头预览。

## 交互与安全

配网热点名称为 `OV2640-Setup`，密码为 `66666666`。配置页提供 SSID 与密码输入框；
提交成功即保存凭据并返回状态页。目标 Wi-Fi 密码仅写入 NVS，不写入日志、不提交到
Git。短按不再切换 LED 颜色；长按确认后先亮绿灯一次 200 ms 作为 STA 切换提示，随后
LED 恢复反映 Wi-Fi 状态。

## 状态与错误处理

进入配网、保存后连接中和重连时 LED 红蓝交替；获得 IP 时蓝灯常亮；连续五次连接
失败时红灯常亮并每五秒重试。空 SSID、过长凭据、NVS 写入失败和 Wi-Fi 模式切换失败
均返回明确 HTTP 错误和日志，原有凭据不会被覆盖。长按切回 STA 时若 NVS 不存在凭据，
记录使用编译期默认凭据的日志；默认凭据同样不记录密码。

## 验证

工程必须通过 ESP-IDF 构建。烧录后短按 GPIO0，手机应能连接 `OV2640-Setup` 并访问
配置页；提交有效凭据后，串口应显示获得 IP，LED 变蓝，手机在同一目标 Wi-Fi 下访问
设备 IP 应可预览 MJPEG 画面。再次短按后热点重新开启；在热点模式下长按 GPIO0 三秒，
热点关闭并使用已保存凭据切回 STA；在 STA 模式下长按则重新按同一凭据发起 STA 连接。
