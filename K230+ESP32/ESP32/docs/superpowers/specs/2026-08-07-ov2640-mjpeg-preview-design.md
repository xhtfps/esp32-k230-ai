# OV2640 MJPEG 网页预览设计

## 范围

在已可稳定取帧的 OV2640 工程中增加局域网网页预览。ESP32-S3 连接用户提供的
手机热点后，浏览器访问设备 IP 即可实时查看摄像头画面。本功能不使用 SD 卡、
文件系统、云端服务或公网访问。

## 架构

新增 `BSP/WIFI` 模块连接指定热点并维护重连；获得 IP 后向串口输出网页地址。
新增 `BSP/WEB` 模块启动 ESP-IDF HTTP 服务器：根路径 `/` 返回预览 HTML，`/stream`
以 `multipart/x-mixed-replace` 格式输出 MJPEG。

MJPEG 处理函数是唯一的持续取帧消费者。对每帧执行“获取 JPEG 帧、写入响应、归还
帧缓冲”的顺序；客户端断开则停止本次流。现有应用层连续取帧任务将移除，避免两个
任务同时占用同一组摄像头帧缓冲。

## 默认参数与错误处理

预览改用 JPEG/VGA（640×480）、画质 10 和双 PSRAM 帧缓冲；该配置优先提高画面
清晰度，实时帧率会低于原先 JPEG/QVGA 的约 26 FPS。Wi-Fi 使用用户提供的热点凭据；
凭据仅保留在本地配置文件中，不写入日志。断线后自动重连；IP 获取失败、HTTP 服务
启动失败、取帧失败和客户端断开均输出明确日志。浏览器与 ESP32 必须连接同一个局域网。

## 验证

工程必须通过 ESP-IDF 构建。烧录后，串口必须输出成功连接热点和网页地址；访问 `/`
应显示实时画面，访问 `/stream` 应返回连续 JPEG 流。关闭页面并再次访问后，画面应能
恢复，且不会持续出现取帧失败日志。
