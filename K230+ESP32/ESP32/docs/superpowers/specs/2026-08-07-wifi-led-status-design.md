# Wi-Fi LED 状态提示设计

## 范围

为现有 OV2640 网页预览工程增加 Wi-Fi 连接状态灯。GPIO48 上的 WS2812 LED 使用
蓝灯常亮表示已连接、红蓝每 500 ms 交替表示正在连接或重连、红灯常亮表示连接失败。

## 架构

LED 模块独占颜色输出和状态任务生命周期，对外增加连接中、连接成功和连接失败三个
状态接口。仅“连接中”状态创建 FreeRTOS 任务以切换红、蓝，避免在 Wi-Fi 事件回调中
阻塞。WIFI 模块在启动和重连时设置连接中；获得 IP 时设为蓝灯常亮；连续五次连接失败
后设为红灯常亮，并每五秒继续发起重连。

## 错误处理与验证

重复状态切换不得创建重复任务或触发异常。烧录后，串口显示成功获得 IP 时 LED 应为
蓝灯常亮；关闭热点后先红蓝交替，五次失败后为红灯常亮；恢复热点后应转回蓝灯常亮。
工程必须通过 ESP-IDF 构建。
